DELL EMC service IPMITOOL

This tool is to be used by DELL EMC service personal and authorized users to access the serial over lan (SOL) console of DELL EMC storage products. To use this tool, open a windows OS "Command prompt' and run the "ipmitool.exe" executable as instructed in the service procedures.

This tool uses software components which may be obtained from the following addresses:
ipmitool: https://github.com/ipmitool/ipmitool
CYGWIN: https://cygwin.com/index.html
A copy of each components licenses and copyright notices can be found in the COPYING directory. 
Patches made to ipmitool can be found in the PATCHES directory.
